«Ежедневник» (Hobonichi) — офлайн-приложение для iPad.
Адрес: https://tumirnur.github.io/Hoponichi/

Все файлы лежат в корне репозитория Hoponichi, без папок.
Обновление: загрузи все файлы из архива в корень репозитория с заменой (Add file → Upload files → Commit).
При каждом обновлении в sw.js увеличивается номер версии (сейчас techo-3).

pdf.min.js и pdf.worker.min.js — библиотека Mozilla pdf.js (Apache 2.0, см. pdfjs-LICENSE.txt).
Старую папку pdfjs (если она есть) и старую папку techo можно удалить.
