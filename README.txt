«Ежедневник» — офлайн-приложение (формат Hobonichi) для iPad.

Как выложить:
1. Открой репозиторий GitHub «Circle» → Add file → Upload files.
2. Перетащи ВСЮ папку «techo» (вместе с папкой и подпапкой pdfjs) → Commit changes.
3. Через 1–2 минуты ежедневник откроется по адресу:
   https://tumirnur.github.io/Circle/techo/

На iPad:
- Открой адрес в Safari → «Поделиться» → «На экран „Домой“».
- Открывай с иконки. Первый раз — с интернетом (чтобы приложение сохранилось), дальше работает и без Wi‑Fi.
- ☰ → войти тем же аккаунтом, что в «Моём дне». Записи, картинки и документы синхронизируются через Supabase, когда есть интернет.

Перенос из Claude:
- В ежедневнике в Claude: «Перенести ↗» → «Скопировать».
- В приложении: ☰ → «Перенести записи из Claude» → «Вставить» → «Перенести».

Документы (PDF и Word .docx):
- Вкладка «Документы» → «＋ Добавить PDF или Word». Страницы файла появляются в конце книги,
  на них можно писать, рисовать, клеить наклейки и картинки.
- В том же списке: «Открыть» с номером страницы — сразу перейти к нужной странице; «Удалить».
- Цветной ярлычок на краю страницы документа — нажми, чтобы открыть список документов.
- Старый формат .doc не поддерживается — сохрани как .docx или PDF.
  Word переводится в страницы приблизительно (текст, заголовки, списки, таблицы, картинки);
  если нужен точный вид — сохрани файл как PDF.

Обновления: заменяй файлы в папке techo. В sw.js при каждом обновлении увеличивай номер версии (сейчас techo-2).
Папка pdfjs — библиотека Mozilla pdf.js (лицензия Apache 2.0, см. pdfjs/LICENSE.txt).
